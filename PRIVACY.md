# Privacy Policy for Sweety Bot

*Last Updated: August 2026*

This Privacy Policy explains how **Sweety** ("the Bot") collects, processes, and protects your information when you interact with it on Discord.

---

## 1. Information We Collect
To function and provide moderation, logging, role management, and AI features, Sweety processes the following data:
- **Server Identifiers:** Discord Server (Guild) ID, Channel IDs, Role IDs.
- **User Identifiers:** Discord User IDs and usernames (used for moderation logs, timeouts, mutes, and autoroles).
- **Message Content:**
  - Slash command parameters (e.g. `/ask`, `/embed`, `/backup`).
  - Messages directly mentioning `@Sweety` to generate AI responses.
  - Messages evaluated in real-time by the AutoMod filter for spam and toxicity prevention.
- **Configuration Settings:** Server custom prefixes, moderation log channels, autoroles, and toggle settings.

---

## 2. Information We Do NOT Collect
- We **never** collect or store private passwords, financial data, or email addresses.
- We do **not** read or store Private / Direct Messages (DMs) between users.
- We do **not** sell, rent, or trade your data to any third parties.

---

## 3. How We Use the Information
Collected data is used strictly for:
1. Executing bot commands and AI responses requested by users.
2. Automating moderation, logging actions, and maintaining server security.
3. Remembering server configuration preferences (e.g., log channels, autoroles).

---

## 4. Third-Party Services
- **AI Processing:** When users ask questions via `/ask` or `@Sweety` mentions, text prompts are transmitted securely via API to AI providers (such as Groq) solely to generate the immediate response. Prompts are not used for training.
- **Hosting & Database:** Data is stored in secure database instances (PostgreSQL/Neon) hosted on compliant infrastructure (Render / AWS).

---

## 5. Data Retention & Deletion Rights
- Configuration data and moderation logs are retained only as long as Sweety remains in your server.
- **Requesting Data Deletion:** Server owners can request complete deletion of their server's database records at any time by contacting the bot developer or removing the bot from the server.
